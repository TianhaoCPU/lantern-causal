# LLM 引导因果膨胀：MIMIC 隐变量发现与缺失图可恢复性试验

**状态：** 可行性方案，已运行合成算例。MIMIC 队列和 LLM 盲测待运行。  
**主问题：** 有意隐藏一个变量后，模型能否根据留下的流程证据和可观测约束，提出与缺失机制相关的隐变量角色？找到候选角色之后，原来的目标关联在什么条件下可恢复？

本方案沿用 [MIMIC 缺失图可恢复性试验](mimic_pilot.md) 的参考队列、遮蔽和目标量。将隐变量发现设为主任务，将给定机制下的目标量恢复设为第二项任务。因果膨胀（Inflation Technique）通过复制图中变量及其祖先，导出原观测分布须满足的约束；它可以排除不相容的图。有限阶未能排除一张图，只表示当前检验没有排除它。[Wolfe 等：因果膨胀](https://arxiv.org/abs/1609.00672)；[Navascués 与 Wolfe：膨胀层级](https://arxiv.org/abs/1707.06476)

## 1. 盲测的对象和参照

| 要素 | 首轮定义 |
|---|---|
| 临床目标 | 延续 NSTEMI 病例：二分 RDW 为 $X$，180 天死亡为 $Y$，年龄与性别分层为 $C$。主恢复目标为高、低 RDW 组的标准化死亡风险差。原论文 Cox HR 的复现仍独立登记。 |
| 完全隐藏的 $U$ | 评分端可以读取 $U$；模型和分析端看不到整列。在植入机制里，$U$ 是同时作用于 RDW 可见性和死亡的共同原因之一。任务优先评分候选是否指出正确的可区分角色，其次才是能否提到隐藏的具体临床字段。 |
| 额外遮蔽的 $X$ | $R=1$ 时可见 $X$，$R=0$ 时只见缺失标记，所得变量记为 $X^\ast$。分析端仍见 $Y,C,R$，以及设计中允许使用的代理或流程指标 $Z$。原 RDW、能重建 $X$ 或 $U$ 的字段及机器标签随之封存。 |
| 植入机制轨 | 用完全合成数据，或以 MIMIC 的基线分布为底再显式生成关系。评分端保存真实图与完整数据分布，设置有共同隐变量、无目标隐变量和观测等价三类。其结构得分由生成机制提供。 |
| MIMIC 回盲轨 | 在有完整参考记录的分析子队列中，选取有时间戳的入科前字段，例如血流动力学指标，再整列隐藏。考查候选的临床相关性、字段命中及可核验性；该字段的真实因果作用不能仅凭论文或隐藏操作当作标准答案。 |

对同一机制的不同命名做等价匹配。在此设计中，「隐藏变量发现」允许答案为一个有依据的角色集合；把角色候选凑巧命名为一个临床指标，不等于识别了该列，也不等于能够还原每位患者的值。在无可区分证据的题目中，保留多种解释或报告信息不足是正确输出。

~~~mermaid
flowchart LR
    Ref["参考记录和已知生成机制"] --> Mask["整列隐藏 U；部分遮蔽 X"]
    Ref --> Score["评分端：保存隐藏变量、真图和参考风险差"]
    Mask --> Obs["本地观测分布"]
    Text["审阅过的字段字典和抽取流程"] --> LLM["LLM 提出候选隐变量角色和图"]
    Obs --> Check["程序校验条件独立和膨胀约束"]
    LLM --> Check
    Check --> Result["输出保留图、排除证据与风险差的恢复状态"]
    Result --> Score
~~~

## 2. 方法与对照

1. **提出可检验的候选。** LLM 根据时间顺序、数据来源和记录流程，输出至多 3 个优先候选：$U$ 的可能作用、连边、代理、依据和缺少的证据。同时预登记无共同 $U$ 的替代机制，并允许「信息不足」。用于盲测的题面隐藏变量名、原文结果和能直接泄露答案的论文标识；原论文复现另行进行。
2. **检验候选。** 本地程序先查图所蕴含的可观测条件独立与已有简单约束，再按规定复制变量和独立源，构造可检验的边缘分布约束。LLM 可以建议优先检验的边缘和顺序，程序须根据原图验证其有效性并计算证据。结果为「有证据排除」「当前未排除」「样本或计算不足」；当前未排除不计为验证了图。
3. **再判断目标量。** 对未排除的机制，分别证明点恢复条件、计算可辩护的范围，或构造同观测异目标的反例。只有仍相容的解释都支持同一个目标值时才报告唯一结果。识别范围和样本不确定性分别报告；排除某图、提名 $U$ 或通过膨胀检验均不能代替这一步。

固定同一份流程证据、候选上限和统计后端，比较规则提图与 LLM 提图；固定同一候选图和可见分布，比较条件独立及已知简单约束、其上增加固定膨胀检验、以及相同计算预算下由 LLM 决定检验顺序。第一组比较测提名能力，第二组比较测额外证据及计算收益。可用现有 [Inflation 库](https://quantum-journal.org/papers/q-2023-05-04-996/) 做求解基线。

有限样本阶段先用开发材料定好候选与约束，再在留出样本做验证。三角算例可针对两个边际率和两个不一致率构造同步区间，只有在区间内所有取值都违反不等式时才拒绝。多个候选或检验视为同一预登记检验族处理，稀疏分层和未解实例单列。MIMIC 患者记录及中间表在获准环境计算，LLM 仅接触可提供给它的流程和字段文本。

## 3. 已运行的合成算例

在一个固定 $C$ 层中，生成不可见的二元共同原因 $U$，两组各占一半。让 $R$（RDW 可见性）、$Z$（假想代理）和 $Y$（死亡）分别以 5% 的独立翻转概率记录 $U$，$X$ 以 20% 的独立翻转概率关联 $U$。这些概率用于造出可验证的例子，不是 MIMIC 的临床参数。

**隐变量角色的证据。** 竞争图规定，$R,Z,Y$ 的每一对各自共享一个独立的潜在原因，三个潜在原因相互独立，且没有直接边或同时影响三者的原因。这张三角图不蕴含可供直接检验的观测条件独立关系。将连接 $R$ 和 $Y$ 的独立源复制一份，用于构造膨胀后的 $Y'$，可保留 $(R',Z')$ 和 $(Z',Y')$ 的原观测边缘分布，同时要求 $R'\perp Y'$。于是

$$
P(R'\ne Y')\le P(R\ne Z)+P(Z\ne Y).
$$

由独立性和两个 50% 的边际率，左侧为 **50%**；由生成的可观测分布，右侧为 **19%**。因此可以排除该独立三角机制。植入的共同 $U$ 模型解释了这些概率；如果允许更宽松的共同原因、直接边或相关的潜在来源，也可能存在相容解释。本例的证据排除的是指定机制，不能唯一命名一个现实中的病因。约束形式沿用[因果膨胀论文的三角示例](https://arxiv.org/abs/1609.00672)。

**目标量能否恢复。** 在额外给出经过校准的代理误分类矩阵、且代理误差在 $U,C$ 给定后与 $X,Y,R$ 无关的正对照中，先从 $(Z,X^\ast,Y,R,C)$ 的观测分布反解含 $U$ 的联合概率。该矩阵须为满列秩。若再有 $R\perp X\mid U,Y,C$ 且各所需层有正的观测概率，可用可见的 $X$ 估计 $P(X\mid U,Y,C)$，再与 $P(U,Y\mid C)$ 合成并对 $U$ 求和，得到原风险差。这个算例的完整数据风险差为 **54.00 个百分点**，完整病例得到 **14.48**，加给定的代理校准后恢复到 **54.00**。这些数值是合成验证；没有给定或验证校准时，应另外论证能否恢复。原试验 C 场景的同观测异风险差反例作为不可唯一恢复的对照。

运行 [causal_inflation_hidden_variable_demo.py](../../examples/proxy_demo.py) 可用精确分数复核。脚本验证上述特定证书和恢复步骤，未执行通用膨胀搜索、LLM 盲测或真实病例分析。

## 4. 先做什么、用什么决定扩展

- **主指标：** 在可判别的植入题中，按独立机制和病例统计正确隐变量角色的候选命中率，同时报告无目标隐变量时的误报率、观测等价题上的错误唯一化率。按论文、机制家族及模板做留出，多个种子不能当作独立病例。
- **关键对照指标：** 在预先知道有可检验证据的错误候选上，统计新增、可复核的排除证书，在真图上监测错误排除，并记录运行成本。恢复指标沿用原方案的风险差误差、范围宽度和错误点估计率。
- **扩大规模的条件：** 先做 RDW 和约 5–9 个能够定义隐藏角色、观测证据与替代图的病例。可从[复现登记表](../../datasets/metadata/replication_registry.csv)中选择单项化验和复合指标。若增加膨胀后在独立留出机制中仍有简单检验得不到的有效证据，并且 LLM 提名优于同证据的规则基线，再扩大病例数；复现原论文与进入隐变量盲测分别登记。

LLM 辅助提出隐变量已有相邻研究，如 [COAT](https://www.jmlr.org/papers/v27/25-2137.html) 和 [TLVD](https://doi.org/10.1145/3774904.3792244)。这项研究可能的贡献是用已知隐藏机制和真实病例形态做盲测，检验膨胀证书能否改变候选隐变量的保留结果，以及这种改变能否进一步影响目标关联的可恢复性。两项增量须各由相应对照支持。
