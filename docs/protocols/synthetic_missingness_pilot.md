# 合成 A/B/C 缺失机制预实验

这个模块把缺失图可恢复性方案的第一步变成可以重复运行的标准库实验。它使用四个固定的人工 $C$ 分层和二元 $X,Y$，先保存完整队列，再按三个已知机制生成 $X^\ast$。分析函数只收到 $X^\ast,Y,C$；完整值、真实机制和参考风险差只用于生成与评分。

## 运行预实验

从项目根目录执行：

~~~bash
lantern pilot --config configs/experiments/missingness_pilot.json \
  --output outputs/missingness_pilot.json
~~~

默认配置包含种子 1–20 和期望遮蔽率 0.3。`outputs/` 被 Git 忽略；报告可以在本地查看，也可以只保留不含逐行数据的汇总。配置中的 `schema_version`、种子列表和期望遮蔽率会被规范化后计算 SHA-256，便于复现同一批运行。

同一人工队列还提供一个与数值评分分开的流程提名原型：

~~~bash
lantern blind-tasks \
  --output outputs/blind_tasks.json \
  --response-template outputs/blind_responses.json
lantern blind-eval \
  --config configs/experiments/missingness_pilot.json \
  --responses outputs/blind_responses.json \
  --output outputs/blind_eval.json
~~~

任务包只含字段定义、目标量、固定图族说明和 9 条人工抽取流程文本（6 条信息充分、3 条保留多个候选）；响应模板带有任务包指纹。`blind-eval` 的规则基线和可选外部 JSON 响应共用同一套候选图校验和统计后端。默认 20 个种子会生成 60 张掩蔽视图；任务与视图的配对重复使用这些视图，不能当作独立研究。任务包不含完整队列、真实机制、参考风险差或评分字段，评估器不调用 LLM，也不接触 MIMIC。完整的临床 E3 题库和供应商接入仍待实现。

## 人工队列与观测边界

固定队列有 1,000 行，$C$ 是四个标签，分别代表年龄组和性别的组合；每层同时包含四个 $(X,Y)$ 计数。这个队列不来自 MIMIC，也不模拟临床效应。完整参考风险差按全体队列的 $C$ 权重计算，精确值为 $39/400=0.0975$，也就是 **9.75 个百分点**。

遮蔽生成器使用

$$
\operatorname{logit}P(R=1\mid X,Y,C)
=\alpha+s(C)+\beta_X X+\beta_Y Y,
$$

其中年龄组和性别的固定分值为 0.4 和 0.2，非零系数为 $\log 2$。每个场景先解截距，使全体行的**期望**遮蔽率为 30%，再用固定种子独立抽取可见性。实际遮蔽率因此会在重复之间波动；程序不重抽以填满某个分层。

分析表只允许三种值：`x=0`、`x=1` 或 `x=None`，以及 `y` 和非空 `c`。生成器在遮蔽时用 `None` 替换隐藏值，不向分析函数传入完整行。程序拒绝非二元值、空分层标签、未映射的生成器分层和重复种子；若调用方自行构造分析表，仍须负责正确遮蔽。

## 三种场景的估计

| 场景 | 生成机制 | 程序输出 | 结论边界 |
|---|---|---|---|
| A | $\beta_X=0,\;\beta_Y=\log 2$ | `standardized_mar`：先恢复 $P(X,Y\mid C)$，再按全体 $C$ 权重计算 RD | 只有在 $R\perp X\mid Y,C$ 且所需的 $(Y,C)$ 层有可见记录时才是点估计 |
| B | $\beta_X=\log 2,\;\beta_Y=0$ | `standardized_visible`：用可见病例估计 $P(Y\mid X,C)$，再按全体 $C$ 权重计算 RD | 只有在 $R\perp Y\mid X,C$ 且所需的 $(X,C)$ 层有可见记录时才是点估计 |
| C | $\beta_X=\beta_Y=\log 2$ | `empirical_bounds`：求每个 $(Y,C)$ 格内遮蔽 $X=1$ 人数的极端可行分配，并返回两套见证 | 只知道观测门时一般不点识别；不会因为两个端点恰好接近就报告唯一恢复 |

范围是完整计数表与观察表相容的有限队列识别范围。端点分配保留每个 $(C,Y)$ 格的可见计数和遮蔽计数，并可用 `complete_counts` 重建。范围宽度、参考值是否落入范围和两种公式的绝对误差都会写入报告。逐次范围和误差同时提供精确分数、概率差和百分点；跨次均值以浮点数汇总。

空分层会被记录为 `insufficient_support`，不会自动赋零、重抽或改变分层权重。`standardized_mar` 和 `standardized_visible` 使用完整观察表中的 $C$ 频率作为标准化权重；它们不会把可见病例的分层分布误当作目标人群分布。

## 解读结果

每个 `runs` 元素包含场景、种子、实际遮蔽率、分层计数、两个带假设名称的估计器、观测门范围和评分字段。`known_graph_baseline` 是实验者把真实场景交给程序后的参考基线；它不代表程序从观测数据识别出了图。场景 C 的基线保持 `point_estimate: null`，即使人工样本的两个端点偶然相同。

`summary` 按场景汇总成功和失败次数、平均绝对误差、范围宽度、参考值进入范围的次数及配对误差对比。20 次遮蔽来自同一个固定人工队列，不能当成 20 个独立临床研究。范围不是置信区间，平均误差也不支持临床外推。

## 默认配置的本地核验结果

2026-11-19 以默认配置运行时，A/B/C 的平均实际遮蔽率分别为 29.63%、29.72% 和 29.86%。三个场景各有 20 次成功计算有限队列范围，全部包含人工参考值，且均得到两个风险差不同的端点见证。场景 A 下 MAR 公式的平均绝对误差为 1.62 个百分点；场景 B 下可见病例公式为 1.31 个百分点。场景 C 的已知图基线不报告点估计。

这些数字只描述该人工队列和固定种子的运行结果，用于复现与回归核对，不是算法优效性或真实临床数据的证据。

同一默认配置下，离线流程任务包包含 9 条任务；规则基线的候选集合全部命中（9/9），3 条歧义任务均保留全部相容图。按每个任务的允许图与 20 个种子配对后共有 260 个任务-掩蔽视图，规则基线报告 80 个点估计；联合遮蔽机制的 100 个配对均没有被错误报告为点估计。这里的任务和视图复用固定人工队列，仅用于核对输入边界、分母和统计状态，不是留出模型结果。

## 核验与下一步

测试覆盖以下性质：两种公式在各自的独立性条件下恢复目标；无支持时显式失败；标准化权重使用全体记录；端点见证重新投影到同一观测门；小计数表的穷举结果与端点算法一致；候选图引用和结构校验；信息不足、超出支持范围和错误格式不被点估计替代；CLI 可从仓库外目录运行。运行：

~~~bash
.venv/bin/python -m unittest discover -s tests -v
~~~

通过合成核验后，可在获准环境内单独实现 MIMIC 参考队列适配，先冻结 RDW 抽取、180 天结局核查、分层映射、种子和盲测提示。当前遮蔽生成器只接受四个人工分层标签。患者级表、原始 MIMIC 字段和 LLM 输入边界不会由这个公开的合成模块自动生成。
