# 多项真实世界研究的因果图审计方法学方案

**方案版本：** 0.2（多研究组合框架）  
**研究类型：** 方法学研究；纳入回顾性与前瞻性非干预性真实世界研究  
**研究对象：** 多个临床问题、多个数据源中的观察性研究对比  
**状态：** 框架方案。每项临床研究须另行形成并锁定研究特定方案、数据字典和统计分析计划。

> 本方案研究的是一套因果图审计方法能否跨研究识别可检验的偏倚假设，不以某一种疾病、药物、检验指标或单个队列作为唯一验证对象。现有 RESEARCH_PLAN.md 中的 ICU 病例只是候选回顾性案例；研究组合还须纳入前瞻性非干预性研究。前瞻性收集可以改善时间顺序、变量测量和见证验证，但本身不提供因果真值。

## 1. 研究目的与范围

真实世界研究（RWE）来自常规临床实践中收集的数据，可包括电子病历、理赔、登记系统及按研究方案前瞻性收集的观察性数据。本项目将每个“研究问题 × 数据源 × 目标人群 × 对比”定义为一个**研究单元**。同一数据集中的不同结局或时间窗，只有在研究问题和目标估计量不同且分别预先登记时，才计为独立研究单元。

方法流程由 LLM 提出竞争性偏倚机制和候选见证变量，符号工具检查图结构是否蕴含可检验约束，统计审计在预先说明的见证假设下检验这些约束，并记录拒绝、未拒绝或不可检验的原因。审计结论针对预先登记的图、变量和假设，不直接证明临床效果，也不自动确定哪条边或哪项见证假设错误。

研究包括三类工作：

1. 在已知真值的合成数据和半合成数据上验证算法正确性、检验校准和方法边界。
2. 在多项回顾性 RWE 研究中评估候选见证的发现、数据质量、审计可执行性和跨数据源复现。
3. 在前瞻性非干预性 RWE 研究中预先收集暴露前协变量、候选见证、时间戳和结局，评估方案执行、测量误差及审计可重复性。

若某个研究问题是治疗效果比较，研究特定方案应采用目标试验模拟的要素组织设计。描述性或预后性问题不强行套用目标试验模拟，而使用与问题匹配的设计和估计目标。

## 2. 研究问题与假设

| 编号 | 研究问题 | 评估方式 |
|---|---|---|
| RQ1 | 符号检查器能否正确判定添加见证后，候选图之间是否出现可检验约束？ | 在真值已知的图和模拟数据上分别评估 soundness、completeness、运行时间及各约束类型的适用范围。 |
| RQ2 | LLM 提出的见证能否提高单位采集成本下的有用审计信息？ | 与随机选择、通用见证库、未经符号筛查的 LLM 建议及专家选择比较。 |
| RQ3 | 针对目标估计量 ψ 选择见证，是否优于以整体图结构为目标的选择？ | 在固定预算下比较对 ψ 的不确定性降低和错误图识别成本。 |
| RQ4 | 自适应采集、错误角色声明和测量误差会怎样影响检验有效性？ | 分别在有效见证、无效见证和不同误差机制下评估错误拒绝率、功效和预算损耗。 |
| RQ5 | 多个假设来源相对独立的见证，能否改善对图假设与见证假设的错误归因？ | 与已知植入真值比较，并与单见证策略对照。 |
| RQ6 | 审计结果能否跨研究预测观察性估计与可比随机试验结果的一致程度？ | 仅在存在足够数量、估计目标可比且相互独立的研究单元时进行校准评估；否则报告案例结果，不报告预测性能。 |

**核心假设：** 经过符号检查、有效性评审和统计校准的见证选择流程，相比未筛查建议及基线策略，可以降低识别错误图或关键偏倚机制的成本。此假设须通过实验验证。符号检查只证明某项约束在给定图和分布假设下成立，不证明候选见证在临床数据中确实扮演所声明的角色。

## 3. 研究组合与研究单元选择

### 3.1 设计覆盖

| 设计层 | 数据来源 | 在本项目中的作用 | 设计重点 |
|---|---|---|---|
| 回顾性开发研究 | 既有电子病历、理赔或临床登记数据 | 建立多种临床问题和数据结构下的审计案例 | 锁定数据版本、入组与时间定义、代码版本、缺失与测量机制；保留独立数据源或时间段作验证。 |
| 前瞻性观察研究 | 新建或扩展的多中心登记/队列，不分配治疗 | 评估前瞻性数据采集能否提升见证变量的时间顺序、测量质量和审计可重复性 | 在治疗决策前定义 time zero 并采集协变量；记录治疗、共干预、结局和缺失过程；不得因审计建议改变临床照护。 |
| 合成与半合成研究 | 模拟数据及受控的数据生成流程 | 提供已知图结构、效应和见证角色的参照真值 | 完整记录生成机制、随机种子及分析代码；受限患者级数据只在获准环境使用。 |

目标研究组合至少包括**两项不同临床问题的回顾性研究和一项前瞻性非干预性研究**；优先覆盖两个以上临床领域、两个以上数据源，并在前瞻性阶段争取多中心实施。该组合是项目设计目标，不是单项分析的样本量或统计功效保证。若合作、伦理或数据条件不允许达到目标，须报告实际覆盖范围，并把前瞻性部分标为试点或未完成，不以回顾性结果替代。

### 3.2 纳入研究单元的条件

每项候选研究须满足以下条件，才能进入确认性审计：

- 研究问题、目标人群、干预/暴露、比较策略、结局和目标估计量可明确描述。
- 关键变量有可追溯的数据源、编码规则和时间戳；可区分治疗前、治疗中及治疗后测量。
- 预期有足够的治疗策略重叠和结局信息，可进行预先规定的估计或约束检验。
- 能说明主要混杂结构、潜在选择机制、数据缺失和测量误差；见证有效性假设可由临床/领域专家审阅。
- 数据使用、隐私、伦理和发布条件已确认。

是否纳入不得依据观察到的治疗效果、p 值、审计结果或与随机试验的一致程度决定。先运行不查看组间结局的可行性检查，再锁定研究单元和转向规则。不得对所有研究使用统一的“暴露人数 ≥500”门槛；每项研究按事件数、效应精度、重叠性、检验功效和预期数据损失做设计评估。

### 3.3 研究登记表

建立 study_registry.csv，每行对应一个研究单元，至少包含：study_id、临床领域、研究问题、回顾性/前瞻性、数据源和版本、国家/中心、研究时期、目标人群、暴露与对照、time zero、结局、估计目标、候选 RCT 参照、样本量/事件数依据、数据访问与伦理状态、协议版本、独立验证集及纳入状态。

现有 ICU 候选案例可保留为回顾性组合的一部分；不得将它们合并成一个病例，也不得假设它们足以代表其他临床领域或前瞻性研究。

## 4. 每项研究的设计和执行

每项研究建立独立的 studies/<study_id>/protocol.md、data_dictionary.csv、analysis_plan.md、队列/采集代码和偏离记录。研究特定协议至少填写下表；未锁定的内容须明确标为待定，不得默认为已核实。

| 要素 | 研究特定方案须预先定义的内容 |
|---|---|
| 临床问题 | 目标决策、适用人群、研究目的；说明属于治疗效果、描述或预后问题。 |
| 人群和场景 | 入排标准、临床场景、中心/数据源、招募或观察起止时间。 |
| 暴露与比较 | 具体策略、剂量/途径或策略版本、分配/记录来源、宽限期及交叉用药处理。 |
| Time zero | 资格判定、策略起始和随访起点的共同定义；描述回顾性时间戳与前瞻性采集流程。 |
| 结局与随访 | 定义、算法/裁定流程、验证样本、随访期限、删失和竞争事件处理。 |
| 估计目标 | 目标人群、治疗策略、结局、对比尺度、处理交叉与删失的策略；治疗效果研究明确 estimand。 |
| 混杂与选择 | 因果图、协变量集、变量时间窗、缺失机制、选择/测量机制及敏感性分析。 |
| Witness | 候选变量、声称角色、目标竞争图、有效性假设、采集成本和检验约束；记录失效或不可检验的情形。 |
| 数据治理 | 数据字典、访问权限、数据版本、伦理/同意或豁免、隐私和发布边界。 |

**回顾性研究：** 在估计效应或查看组间结局前，冻结队列代码、变量映射、图和分析计划。记录诊疗流程随时间变化、数据表覆盖变化、医嘱与实际给药差异及潜在随访缺口。必要时使用新的数据源、中心或时间段作外部验证。

**前瞻性研究：** 在首位研究对象入组前，冻结方案、结局定义、采集表、数据管理计划和分析计划。优先在治疗决定之前或 time zero 同步收集关键协变量和候选见证；记录采集时间、采集者、未采集原因、后续治疗和共同干预。研究不分配治疗；研究人员不得向临床团队反馈审计结果以改变照护。根据主要估计量的精度或主要测量/审计指标进行样本量设计，并考虑中心聚类、失访和见证缺失。

每个前瞻性研究单元应预先指定可行性和停止标准，包括招募速度、关键变量完成率、随访完成率、治疗组重叠性和安全/伦理要求。前瞻性设计减少部分时间顺序及测量不确定性，但残余混杂仍可能存在。

## 5. 数据层级与访问边界

| 层级 | 数据 | 用途 | 管理要求 |
|---|---|---|---|
| T1 | 自行生成的潜在因果图和模拟数据 | RQ1–RQ5 真值验证、功效与错误率校准 | 完整记录生成机制、随机种子及分析代码。 |
| T2 | 回顾性 EHR、理赔或登记数据 | 多研究开发、跨数据源复现和真实数据审计 | 按数据源许可与机构审批处理；记录数据版本、字段覆盖和数据清理规则。MIMIC-IV/eICU 可作为现有 ICU 候选数据源，不限定研究组合。 |
| T3 | 前瞻性非干预性队列/登记 | 测量与执行验证、前瞻性审计 | 按中心完成伦理审查、同意/豁免、数据管理和监查安排；明确研究与临床照护边界。 |
| T4 | 半合成数据 | 保留真实协变量/缺失特征，同时植入已知治疗和结局机制 | 数据生成逻辑及已知真值须可审查；受限患者数据不离开获准环境。 |
| 参照 | 随机试验、已验证的外部研究或临床登记 | 在估计目标可比时评估方向或校准 | 不把不同人群、干预、随访或统计尺度造成的差异解释为图审计的成败。 |

所有 LLM 提示默认只可使用公开资料、数据字典、代码和合规的汇总信息。患者行、临床文本或可识别衍生信息，仅可在相应数据使用协议、机构审批和安全环境明确允许时处理；日志不得保存患者级内容。

## 6. 因果图和见证变量

### 6.1 图的登记

每项研究至少登记：

- G0：分析开始前由研究团队提出的基线因果图及识别假设。
- G1...Gk：临床/流行病学专家与 LLM 提出的合理竞争图，保留来源和分歧。
- 变量是观测、潜在、代理或选择变量的状态；图的时间顺序、边、目标估计量及识别条件。
- 哪些图差异会改变目标估计量、点识别状态、界限或临床决策结论。

专家应在查看研究组间效应估计和审计结果前审阅候选图。LLM 产生的图只作为候选假设，不作为专家意见或证据来源的替代。

### 6.2 见证类型及有效性

候选见证可包括负对照、潜变量代理、多指标测量、工具变量、时间锚点、测量过程变量或其他研究特定变量。每个 witness.json 至少记录定义、来源、时间窗、成本、缺失率、误分类验证、目标竞争图、声称角色、必要假设、符号检查结果、专家审核、提出者和版本。

见证的临床角色必须分别论证。例如，负对照需论证其与暴露/结局不存在不允许的因果通路；代理变量需给出潜变量测量模型及误差依赖假设；工具变量需讨论相关性、独立性、排除限制和单调性。多个相关变量、专家认可或符号检查通过，均不能单独证明有效性。

符号检查的结论限定为：在指定图、变量测量状态和分布族下，图是否蕴含特定 CI、Verma、tetrad/rank 或 IV 不等式约束，以及竞争图是否蕴含不同约束。对图可区分性的判断与统计检验的有限样本功效分开报告。

### 6.3 审计结论用语

- **被拒绝（rejected）：** 数据在指定检验和多重性规则下与已登记图—见证假设组合不相容。不得直接表述为“因果图已被证伪”。
- **未拒绝（not rejected）：** 当前数据未拒绝这些约束；不代表图正确或见证有效。
- **不可检验（untestable）：** 没有可用约束、数据质量/功效不足、见证假设无法支持，或关键变量不可观测。

拒绝时同时评估图结构、见证角色、测量模型、选择机制和检验实现等可能原因。只有有额外独立证据时才归因至特定图边或见证假设。

## 7. 统计分析与跨研究综合

### 7.1 研究特定因果效应

每项研究先确定目标估计量和识别假设，再选估计器。倾向评分加权、标准化、AIPW/TMLE、边际结构模型或其他方法须依据研究设计和变量时间顺序选用，并说明缺失处理、positivity、模型诊断、方差估计及敏感性分析。不得把所有研究机械套用同一种估计器。

若研究包含治疗宽限期或动态策略，可考虑 clone–censor–weight，并须在研究特定分析计划中定义离散时间、偏离规则、删失权重、治疗前协变量历史和极端权重处理。没有宽限期问题时不强制使用该方法。前瞻性收集不会自动消除指征混杂；回顾性与前瞻性分析均须处理各自的选择和测量机制。

主要效应分析报告估计值、95% CI、重叠性、权重/标准化诊断、有效样本量、模型表现和对关键假设的敏感性分析。不同研究的目标人群、治疗策略、结局或统计尺度不一致时分别报告，不强行合并。只有 estimand 和设计足够可比时才进行分层或随机效应综合，并报告研究间异质性。

### 7.2 缺失、测量与未测混杂

按研究报告缺失比例、缺失原因、变量测量来源及组间差异。插补方法和完整病例/缺失非随机敏感性分析由研究特定方案规定。暴露、结局和见证变量的算法应通过抽样核验、外部验证或前瞻性重复测量估计误分类。负对照、定量偏倚分析和 E-value 可作为补充；它们不能验证因果图或代替临床论证。

### 7.3 自适应检验与错误率

见证选择和统计检验必须分离：规划阶段仅使用预先允许的信息；确认性检验使用独立的留出数据、时间段、中心或经严格证明有效的 e-value/其他序贯方法。按研究单元和约束族规定多重检验控制。交叉验证不能自动解决对同一数据反复筛选和检验的问题。

错误率保证必须明确其条件。若见证的角色声明无效，检验可能拒绝真图；不能假设 LLM 幻觉只增加成本。未经独立审查的角色声明应进入探索性分析、触发弃权，或纳入明确的复合假设检验。分别报告“在有效见证条件下的错误拒绝率”和“包含角色误报机制时的整体错误率”。

### 7.4 随机试验参照

只有在目标人群、治疗策略、随访、结局定义和统计尺度足够可比时，才计算 RWE 与 RCT 的差异或一致性。记录是否需要人群标准化/运输、RCT 结果不确定性及剩余不可比因素。单个 RCT 参照或单个临床案例不用于宣称 RQ6 预测性能；跨研究校准须以研究单元为抽样单位，并通过按研究/中心/时间留出的验证避免泄漏。

## 8. WitnessBench 与实验

### 8.1 基准组成

| 组件 | 数据 | 主要目的 |
|---|---|---|
| A：合成图 | 多种 ADMG、效应机制、见证角色与测量误差 | 检验图约束发现、检验校准、自适应错误率及归因准确度。 |
| B：半合成数据 | 多数据源的真实协变量/缺失结构，叠加已知治疗与结局机制 | 评估方法在现实数据形态下的性能，同时保留真值。 |
| C-R：回顾性研究组合 | 多临床问题、多数据源的既有 RWE 研究 | 评估候选见证的可得性、数据质量、审计执行和外部复现。 |
| C-P：前瞻性研究组合 | 一项或多项前瞻性非干预性队列/登记 | 评估预先采集的完整度、时间顺序、误分类、跨中心复现和实际成本。 |
| D：人工标注集 | 图合理性、见证角色、文本抽取和数据质量审核 | 建立专家参考标签；盲法、裁决和一致性统计须预先规定。 |

C-R 和 C-P 的研究单元须来自多个临床问题。若只有单个临床领域或单个中心，结果按该范围报告，不宣称跨领域/跨中心有效。

### 8.2 实验

| 实验 | 评估内容 | 主要指标/决策 |
|---|---|---|
| E1：符号检查器 | 约束正确性、类型覆盖、规模表现 | soundness、completeness、运行时间；不达标时缩小支持范围。 |
| E2：采集效率 | ψ 定向、全图目标、随机、通用库及专家基线 | 成本—识别曲线、剩余 ψ 不确定性；以真值已知的数据为主要比较集。 |
| E3：角色误报 | 有效与无效见证、不同错误率和差异性测量误差 | 分条件错误拒绝率、功效、弃权率和预算损耗；不预设所有幻觉率下均能控制错误率。 |
| E4：自适应校准 | 规划与检验拆分、序贯策略和多重性 | 留出数据上的 I 类错误和功效；未校准的方法仅作探索性分析。 |
| E5：错误归因 | 错图、无效见证或两者同时植入 | 归因准确率及不确定性；比较单见证与多见证。 |
| E6：测量误差 | 回顾/前瞻性核验标签与半合成注入 | 误分类指标、校正后错误拒绝率和适用边界。 |
| E7：回顾性组合 | 多个预登记研究单元 | 可执行率、有效见证比例、研究间异质性及外部复现；不以“必须拒绝 G0”为成功条件。 |
| E8：前瞻性实施 | 预先采集的一个或多个非干预性研究单元 | 招募/随访完成度、测量质量、审计重复性、成本和方案偏离。 |
| E9：RCT 校准 | 具备可比 RCT 参照的多个独立研究单元 | 校准和预测性能；先按可比研究数量及模拟功效确定分析是否可行，样本不足时只作描述。 |
| E10：消融与模型比较 | 移除检索、符号筛查、ψ 定向或多见证整合 | 对预先指定主要指标的影响及计算/采集成本。 |

所有方法指标报告不确定区间。划分训练、调参和测试时按图生成实例、研究单元、中心或时间段拆分；不得将同一研究的记录随机拆到训练和测试集后声称外部验证。阈值、主要指标和失败判据须在测试集解盲或前瞻性入组前登记。

## 9. 偏倚、伦理与数据治理

| 风险 | 控制措施 |
|---|---|
| 研究间临床/数据异质性 | 预登记研究组合；按领域、设计、数据源和目标估计量分层报告；避免不合理汇总。 |
| 指征混杂、选择和时间偏倚 | 每项研究绘制因果图、对齐 time zero、记录选择流程并做研究特定敏感性分析。 |
| 见证无效或假设重叠 | 记录有效性假设和来源；对依赖同一机制的见证不视为独立证据；允许输出不可判定。 |
| 前瞻性测量负担与失访 | 预试运行采集表、记录缺测原因、监测中心差异和失访；按方案评估可行性。 |
| LLM 幻觉和自动化偏差 | LLM 输出保留为候选；独立专家审阅；不允许模型自我验证临床有效性。 |
| 自适应检验造成错误率膨胀 | 独立测试信息、适当多重性控制和校准；未证明有效的检验标为探索性。 |
| 隐私、数据外传或再识别 | 遵从数据使用协议、机构政策和安全环境；日志不记录患者级信息；发布前审查披露风险。 |
| 研究参与者权益 | 回顾性与前瞻性研究分别向 IRB/伦理委员会确认审查、同意或豁免要求；前瞻性研究按获批流程招募和随访。 |

## 11. 里程碑和停止/转向规则

| 阶段 | 主要工作与关口 |
|---|---|
| 1：组合设计 | 建立跨临床领域的候选研究登记表；确认回顾性数据源、前瞻性合作中心、伦理/数据访问和初步可行性。 |
| 2：方法基准 | 完成合成/半合成真值设计、符号检查器验证及检验校准；不达预设门槛时限制后续确认性主张。 |
| 3：回顾性执行 | 锁定多个研究单元的方案、数据字典和分析计划；完成内外部复现和研究间异质性分析。 |
| 4：前瞻性实施 | 完成伦理审批、试运行、入组/采集和质量监测；在首位对象入组前锁定方案与指标。 |
| 5：综合分析 | 按研究单元完成审计证书；只对 estimand 可比的研究作汇总或 RCT 校准。 |
| 6：发布 | 发布方法、合成数据/生成器、允许发布的代码和汇总结果；复核许可、伦理与披露风险。 |

**停止或转向规则：**（1）某研究单元的暴露、结局或 time zero 无法可靠操作化时，移出确认性组合并记录原因；（2）回顾性研究缺乏重叠或有效样本信息时，不报告超出数据支持的效应结论；（3）前瞻性招募、变量完成或随访未达到预设可行性标准时，报告试点结果并修订实施方案，不补写为确认性验证；（4）约束检验未校准或见证有效性无法支持时，标记为探索性/不可判定；（5）可比 RCT 或独立研究单元不足时，不声称 RQ6 的校准或预测性能；（6）所有转向依据均不得使用未盲态的治疗效应方向或审计结论。

## 12. 各研究启动前清单

- [ ] 研究单元已登记，且覆盖的临床领域、设计和数据源符合组合目标。
- [ ] 独立的研究特定 protocol、数据字典和统计分析计划已审阅并锁定。
- [ ] 对治疗效果问题，已明确目标试验要素、estimand、time zero 和目标策略；其他问题已说明适用设计。
- [ ] 暴露、结局、协变量和候选见证的时间窗、来源、版本及验证方式已记录。
- [ ] G0、竞争图、见证有效性假设和符号约束已在组间结果揭盲前登记。
- [ ] 已完成样本量/精度、事件数、重叠性、失访/缺失、检验功效和测量成本评估。
- [ ] 已确定训练/规划与独立检验数据的拆分及多重性控制。
- [ ] 前瞻性研究已取得所需伦理批准，锁定招募、数据管理、随访、同意/豁免和偏离流程。
- [ ] 数据使用许可、安全环境、LLM 边界及发布计划已获确认。
- [ ] RCT 参照或跨研究汇总已完成 estimand 可比性审核；不可比时限定为描述性比较。
