# 处理过程

## 输入

构建脚本读取工作区的归档 PubMed 报告、下载清单、摘要筛选 CSV、病例复现登记 CSV、OCR 文档清单，以及每篇全文的 OCR JSON/TXT 与原 PDF。不会重新联网检索或重跑 OCR。源摘要检索范围有新风险因子与预测指标关键词限制，因此这些论文不代表全部 MIMIC 文献。

## 数据流

~~~text
PubMed 报告 + 下载清单 ──按 PMID 核对──┐
摘要筛选 + 复现登记表 ──保留出处和状态─┤
OCR JSON/TXT + PDF ──核对 ID、哈希、页数─┤
                                    ↓
                     除去 OCR TXT 元数据前言
                     仅删除独立 <MERGE> 布局行
                                    ↓
                 每篇 TXT + JSON + 摘要 TXT
                 全库 JSONL + 轻量索引 + 质量报告
                                    ↓
                 逐篇内容、页码偏移与来源一致性校验
~~~

## 处理决策

以 PMID 为连接键，并要求文献报告、下载清单和复现登记表的 ID 完全一致。题名和 DOI 与清单交叉核对。原作者显示字段可能截断为前三名及 `et al.`，因此使用 `authors_display`，不伪造完整作者列表。

全文使用 OCR JSON 的逐页正文，而不是再次解析 Markdown。先核对聚合正文是否与逐页正文相同，再核对原 TXT 去除前言后的正文一致。PDF 与源 OCR 元数据的 SHA-256 也须一致。检查所有页的序号、状态和文本内容；完整文献不允许缺页或空正文。

仅移除页内独立的 `<MERGE>` 布局标记行，其余文字保留。重建 `[Page n]` 分隔并记录每页正文的字符位置。TXT 中的表格沿用源 OCR 已展平的制表符分隔内容；JSON 同时保留表格 HTML，以供核查合并单元格。标题索引直接来自源标题块，不通过语义模型猜测章节。

缺少全文的论文仍输出 JSON 和摘要 TXT，明确标为 `abstract_only`，正文为 `null`。摘要与全文不混用。所有论文都保留原摘要初筛和复现登记状态，未标注隐变量、因果方向或可恢复性答案。

输出先在临时目录生成，全部构建检查完成后才放入数据集的生成目录。再次运行构建需要显式指定 `--replace-generated`，避免无意覆盖生成物；原始文献不被修改。构建后运行验证脚本，并保存来源核对记录。

## 验证和质量解释

验证脚本逐篇核对 TXT 与 JSON、单篇 JSON 与 JSONL、页码及字符范围、索引和汇总计数、来源快照及哈希；启用 `--workspace` 时进一步检查原始 OCR 和 PDF。当前源 OCR 全部页面已正常结束，35 个提示页仍保留在报告中。这些结构检查不等于人工全文校对，也不保证所有图像内容均被转写。

数据集可以独立复制并读取；原 PDF、完整原 OCR JSON 和原图块仍留在工作区。若要继续做因果隐变量盲测，需另外构建有明确输入边界和答案来源的任务，避免从本参考语料直接向模型泄露题名、摘要或原文结果。
